# Leonida Legend — the GTA VI platinum tracker & guide

A complete, offline trophy guide for Grand Theft Auto VI on PlayStation 5:
all 55 trophies with a step-by-step guide for each one, a five-phase
roadmap to the platinum, the list's one missable trophy flagged everywhere
it matters, and a working progress tracker — earned ticks, per-trophy
counters, a spoiler shield for story trophies, and progress you can export
and import as a file. Static files only: no build step, no accounts, and
nothing loaded from the network.

## Run it

Any static file server pointed at `app/` works. With Node:

```
node serve.ts            # http://localhost:8080
```

or serve `app/` with whatever you already use. The guide keeps working
with the network off — progress lives in the browser's local storage.

## What is inside

- **Tracker & guides** — every trophy grouped by roadmap phase, with its
  official name, description and grade, its type and time estimate, a
  checkbox, and — for the 20 counted trophies — a live counter (250
  stunts, 42 range golds, $250,000 laundered…) that earns the trophy when
  it reaches its target. Clicking a row opens its full guide: the method
  in this guide's own words, a step-by-step list, a "watch out" pitfall
  note where one exists, and the sources the entry rests on, cited beside
  it.
- **Roadmap** — the platinum in five phases (story first, then the 100%
  engine, collectibles, strangers, and the crime/money cleanup), with the
  published figures up top: difficulty 4/10, about 200 hours, one
  playthrough, one missable, no online trophies.
- **Missables** — the one trophy that can be lost, Positive Mental
  Attitude, with its protection plan, plus the short list of trophies
  that only look missable and are not.
- **Sources** — the official PlayStation list is the authority for every
  name, description, grade and count; published guides (PowerPyx,
  SixShore and others) are cited for methods and estimates, and the
  bibliography says what each one was used for.

## Handing it in

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `app/` and `screenshots/` into the output directory and
writes `dossier.json` with the vendored make.fun library — the file the
gate rebuilds and compares byte for byte. The screenshots in
`screenshots/` are real renders of the app (headless Chromium, fixed demo
progress), listed in `shots.json` and reproducible with
`tools/take-screenshots.mjs`.

## Layout

```
app/          the guide itself — index.html, style.css, app.js,
              render.js, store.js, data/trophies.json
screenshots/  the four entry screenshots
main.ts       the hand-in program (builds dossier.json)
serve.ts      a pocket static server for previewing the app
vendor/       the make.fun frontend library, used unchanged
tools/        the data builder and the screenshot script
```

The trophy data file is generated by `tools/build_data.py`, which takes
the official names, descriptions and grades from the previously published
entry's data and layers this guide's own text — guides, steps, phases,
times and sources — over them, so the official fields can never drift.
